## 项目验证使用

顶栏选择“项目验证”，输入项目 ID，提示词可留空使用后端默认 CBMC。点击“提交验证”创建项目；已有项目选择“查询已有项目”。页面每 2 秒串行查询进度与结果，完成、失败、取消或无任务时停止。请求错误后可手动查询重试；普通提交不会覆盖项目。“强制提交验证”需确认，会先停止旧验证并永久删除该项目旧任务文件及数据库映射；不存在的项目也可使用。重置中继续轮询，成功后刷新工作台历史和选择，保留创建表单输入。

切换回单 IP 工作台不会清空输入或中断任务订阅，项目自动查询会暂停，返回后续查。修改项目 ID 会清除旧项目展示并停止查询。每个任务可下载结果文件，也可用“查看任务”返回单 IP 工作台查看会话。

项目任务卡以 IP 标识为主标题，来源为进度接口的 `tasks[].ip_id`，对应上游 `ipMsg.entity.basicInformation.id`（如 `B_TcProcess`），不是数字 `ipId`，也不是 IP 名称 `name`。卡片另行显示明确标注的“任务ID”；历史任务的空值或缺字段显示“未提供 IP 标识”，仍可用任务 ID 区分。进度和结果接口的任务类型均包含 `ip_id`，结果文件匹配与“查看任务”仍使用 `task_id`。此展示仅用于项目页，单 IP 工作台保持原有功能。

单 IP 聊天使用与历史归约见 [聊天交互](聊天交互设计.md)。
