# 工厂交互

页面 URL 同时包含非空的 `projectId`、`jobName`、`buildId`、`toolName`、`executionId` 时，本地数据集、课题二、三均显示自动填充且只读的项目 ID，五项原字符串作为 `keti5` 随提交传递。本地提交到 `/task/create_task`，后端以 `keti5.projectId` 原字符串关联任务；课题二、三沿用项目提交。任一参数缺失或为空时整组忽略，本地不显示也不要求项目 ID，提交不携带工厂参数；其他参数不展示，也不改变验证工具选择。

任务详情依据任务自身的工厂参数启用“上传到工厂”，与当前页面 URL 无关。优先读取验证状态，只有 completed、failed、cancelled 表示结束，其余状态上传前确认中间结果。每次请求期间禁用按钮，完成后可再次上传，显示最近结果或错误。上传失败时完整以纯文本显示后端错误详情（含中文说明、上游 HTTP 状态、JSON/非 JSON 响应或具体连接原因），保留换行、长行自动折行，限高区域可滚动及键盘聚焦浏览，不截断、不解析 HTML、不撑宽侧栏。
