# 聊天交互

任务详情中央对话区可发送消息或暂停，右侧四个按钮始终竖列切换详情视图。左侧任务项以英文 IP 名字为主、taskID 小字为辅；对话顶栏显示 IP 名字、projectID 和 taskID，无项目归属显示“—”。IP 名字依次取 ip_name、ip_id、taskID，不翻译英文标识；详情缺少归属时使用选中任务的列表记录补齐。点击任务列表回到对话。运行中可以发送补充；暂停或结束后发送，会在原任务会话继续。`idle` 表示对话结束无新报告，`paused` 表示已暂停；原验证结论保留，不把普通聊天结束当成验证完成。

草稿按任务 ID 隔离，切任务、视图或项目模式均保留。发送成功仅清空未再编辑的当前草稿，失败保留输入并显示错误。发送和暂停请求期间禁止重复操作；无任务、准备中、删除中禁止操作，空白消息不能发送。暂停等待后端确认，不以断开订阅代替。

发送和暂停确认后重新订阅全量历史与实时事件，不插入本地用户消息。显式 user 展示全部用户输入，event_id 去重，同文本的不同消息仍保留；旧 RPC 用户开始/结束合为一条，首 prompt 不与任务提示词重复。助手增量、最终快照和工具按轮次归约，旧轮状态不能结束新轮。流关闭后重新读取元数据与文件，已有报告不会切走当前对话。

切任务、删除、项目永久删除或强制重建时作废旧请求；迟到响应不能切回旧任务、清空草稿或覆盖新状态。项目删除或强制提交成功以刷新后的历史列表判断原选择是否存在，缺失时清除旧展示并选择剩余任务；输入表单不重建。
