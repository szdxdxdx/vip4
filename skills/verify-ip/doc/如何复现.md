
## 如何复现验证结果

复现验证结果（即重新执行一次 IP 验证）需要以下内容：
- 能够调用 SKILL 的 AI Agent
- 当前 SKILL，以及所要求的验证工具及运行环境
- 与原实验一致的待验证 IP，包括形式模型、源码实现及相关依赖

复现步骤如下：
1. 准备与原验证一致的 IP 输入
2. 为复现实验指定一个新的、空的验证工作目录
3. 明确要求 AI Agent 使用本 SKILL 重新执行完整验证任务
4. 在新 suite 中查看验证结论，原 suite 的结果进行比较

需要用户明确告诉 Agent 的内容：
- 要验证那个 IP，形式模型和源码文件的路径在哪
- 验证结果保存到哪（验证的工作目录在哪）
- 如果套件目录已存在（例如之前的任务被中断了），是在原有基础上继续，还是另建
- 使用哪个验证工具，是CBMC、CPAchecker 还是 KLEE
  一次任务只能选一个工具，对应一个验证工作流，一个验证套件。

注意：
- 用户以对话的方式，用提示词为 Agent 提供指导，验证流程全程由 AI Agent 自动完成
- 不建议用户再 Agent 工作过程中修改任何文件或配置，也不建议暂停 Agent 的执行
- 验证完成（报告生成完毕）后，suite 视为只读状态
- 若修改了外部文件（如 IP 源码、文档等），则复现结果不再与原 suite 等价，需视为新的实验条件
